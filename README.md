This mod introduces an expansive palette of **75 new skin colors** to *RimWorld*.

![Image](https://imgur.com/Ag2bKfL.png)  
Adds new colours to:  
- **Dirtmole**  
- **Impid**  
- **Waster**  
- **Highmate**
- **Starjack**
